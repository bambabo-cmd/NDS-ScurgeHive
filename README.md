## 치트·편의 기능

| 조작 | 기능 |
|---|---|
| SELECT+START | 하단 화면 치트 메뉴 열기 |
| 메뉴에서 ↑↓ / ←→ / B 또는 SELECT+START | 항목 이동 / 값 변경 / 닫기 |
| SELECT+Y | HP·공격 에너지 회복, 감염률 0. 유한 모드에서는 회복 1회 소모 |
| SELECT+X | 화면의 활성 대상 중 HP가 1보다 큰 대상의 HP를 1로 낮춤. ‘약화 N’으로 실제 변경 수 표시 |

| 치트 항목 | 선택값·효과 |
|---|---|
| 데미지 감소 | 원래 피해·1/2·1/3·1/4·1/5·1/10·0(무적) |
| 공격력 강화 | 1·2·3·4·5·10배·한 방 |
| 경험치 배수 | 1·3·5·10·20·30배 |

| 공격력 설정 | 탄환 확대 배율 |
|---|---|
| 1 / 2 / 3 / 4 / 5 / 10 / 한 방 | 1 / 1.25 / 1.5 / 1.75 / 2 / 3 / 3배 |

크기는 발사할 때 정해지므로 다음 탄환부터 새 값이 적용됩니다. 적 탄환과 이동 탄환이 아닌 일부 능력은 확대하지 않습니다. 실제 적 조우에서의 확대 탄환 명중과 SELECT+X 대상 분류·HP 변화는 추가 검증 대상입니다.

회복 잔량은 세이브포인트의 원래 회복 절차가 끝나면 선택한 한도까지 충전됩니다. 한도를 늘리기만 해서는 충전되지 않으며 제한 없음에서 유한 모드로 돌아오면 세이브포인트에서 충전해야 합니다. 설정·잔량은 자동 기록되고 두 진행 슬롯에 공통으로 적용됩니다. **치트 설정 저장과 게임 진행 저장은 별개**이므로 진행은 원래 세이브포인트에서 저장하세요.
